# Script-anchored caption alignment (lib/script_alignment.py): faster-whisper word times are anchored
# onto the known script tokens -> alignment_method = "asr_anchored" (the documented default; the
# spec's whisperX "forced" alignment is not part of this repo, see docs/topic-tutorial-v3-fixes.md §5).

# NOTE: tools/analysis/transcriber.py pre-decodes audio with ffmpeg (Transcriber._audio_input) instead of

# AttributeError on demuxed streams. Keep ffmpeg on PATH (lib/voice_lab.asr_coverage decodes with librosa for the same reason).
